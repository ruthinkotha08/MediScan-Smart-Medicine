# MediScan — Streamlit

MediScan is a Streamlit prototype for medicine product verification.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Demo IDs

- MED001 — valid demo
- MED002 — valid demo
- MED003 — intentionally expired demo

The current records are fictional. A production version should use validated, authoritative medicine/product data.

## Deployment

This project can be deployed from GitHub using Streamlit Community Cloud.
